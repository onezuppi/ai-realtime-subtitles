Companion program

In the "Computer" mode the extension talks to model servers on 127.0.0.1:8083 (speech) and 127.0.0.1:8082 (translation). In the "Bridge" mode it talks to the companion program through the browser instead, which works behind a VPN extension or in a Tor window. Install the bridge with companion/install-bridge.
